# smartmontools-sdk native core

C++ SMART/health-monitoring core, vendored from the [smartmontools](https://www.smartmontools.org/)
project and built as a static library (`libsmartmon.a`) plus a stable C ABI
(`capi/`) for language bindings under `bindings/`.

See `../docs/architecture/overview.md` for how this tier fits into the monorepo.
